# 🛒 E-Commerce Frontend Website

A modern and responsive E-Commerce frontend website built using **React.js**, **Next.js**, and **ShadCN UI**.  
This project provides a clean shopping experience with modern UI components, responsive layouts, and reusable frontend architecture.

---

## 🚀 Features

- Modern responsive UI
- Product listing page
- Product detail page
- Shopping cart interface
- Category sections
- Navbar and footer
- Mobile-friendly design
- Reusable UI components using ShadCN
- Fast performance with Next.js
- Clean folder structure

---

## 🛠️ Tech Stack

- **React.js** – Frontend Library
- **Next.js** – React Framework
- **ShadCN UI** – UI Components
- **Tailwind CSS** – Styling
- **TypeScript / JavaScript**
- **Lucide React Icons**
